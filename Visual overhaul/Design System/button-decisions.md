# Quiet Precision button extension

Proposed 5 October 2026. Resource root: `C:\Users\tanzi\OneDrive\App Development\TFlex\Visual overhaul`.

Recommended family: Quiet Actions. Use filled violet sparingly for primary tasks, outlined neutral secondary actions, transparent utilities, soft violet persistent tools and explicit red destructive actions. Alternate composition: Command Groups for tightly related secondary commands.

Retain the icon/panel/dock palette, 9 px control radius, rounded outline vector grammar, 6 px icon-label gap and 140 ms transitions. Primary hover and pressed tokens extend the same violet identity. Segmented inner radius is derived from the 9 px group minus 3 px inset, not a new arbitrary shape.

Distinguish intent from semantic state. Pressed isn't selected, unavailable isn't loading and simulated activity isn't real completion. Bind states to actual commands/capabilities. Keep meaningful labels and native platform controls.

User acceptance remains pending. The resources demonstrate the proposal; no application source was changed.
