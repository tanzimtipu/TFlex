# Preview validation

Rendered in local headless Microsoft Edge. All category compositions fit 736/520/360/320px without horizontal page overflow and produced no JavaScript page errors. Inspected Home light/dark and Viewing Controls light screenshots. Literal fragments and token JSON checked.

Invalid page input produces an error; page 34 disables Next; mode selection is exclusive; chosen zoom appears in the status. The preview does not navigate or zoom real PDFs and simplifies the existing command inventory. Native shortcuts, real fit calculations, page labels and canvas/tool behavior require app checks.

These are interactive design references, not completed application implementations.
