# Preview validation

Rendered in local headless Microsoft Edge. All category compositions fit 736/520/360/320px without horizontal page overflow and produced no JavaScript page errors. Inspected Home light/dark and Viewing Controls light screenshots. Literal fragments and token JSON checked.

The specimen renders in both themes and at narrow widths. Supporting text contrasts are recorded in supporting-text-contrast.json and exceed 4.5:1. Font fallback, native text scaling, localization/shaping and actual UI/PDF isolation require application checks.
