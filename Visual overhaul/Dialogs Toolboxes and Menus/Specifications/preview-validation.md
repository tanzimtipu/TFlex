# Preview validation

Rendered the self-contained preview in local headless Microsoft Edge. Inspected Task Dialog light, Stamp Picker dark and Context Toolbox light screenshots.

Passed: invalid page range disables submit; valid range produces correct unique-page count; Extract/Split changes the primary verb; empty image list disables create; example image add/reorder/remove updates order/count; stamp choice changes selection and preview; blank comments disable submission; meaningful comments enable it; Escape closes comment expansion. Five examples rendered in light/dark. All fit 736, 520, 360 and 320px without horizontal page overflow. No JavaScript page errors. Fragment format/size and JSON tokens were checked.

Limits: examples are normal-flow component illustrations, not functioning modal/portal overlays. Close/Cancel, engine operations, color editing, deletion, menu commands and placement announce illustrative outcomes; they do not modify documents or files. Images are example filenames with schematic thumbnails. The range parser counts unique ascending numeric ranges within a 34-page example; production must use its engine's actual grammar/order semantics. No real accessibility focus trap, native menu navigation, backdrop inertness, canvas transform positioning, persistence, IME integration or Windows DPI tests were performed. The implementation plan requires those checks against real application components.

Offline illustrations use the original shared icon concepts plus matching small vector additions; inline illustrations use supplied Lucide glyphs. The visuals are references, not production code to copy verbatim.
