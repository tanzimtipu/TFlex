## Phase 97 - Windows PDF-family file associations: Jovrel as a selectable default-app candidate (CEO commission from TFL-375, delivered as TFL-518, 2026-10-04)

**Operator request (product terms, TFL-375 / CEO commission TFL-518).** Jovrel must appear as a registered/selectable app in Windows Settings > Apps > Default apps > "Set default file types" and in Explorer's "Open with" list for the full PDF-family set the operator showed, not only `.pdf`. The operator's screenshot lists the Windows default-app rows, every one of which currently resolves to Adobe Acrobat except `.pdf`:

- `.aaui` - Acrobat User Interface
- `.bpdx` - Acrobat Batch PDX
- `.fdf`  - Acrobat Forms Document
- `.pdf`  - already Jovrel (Jovrel PDF Document)
- `.pdx`  - Acrobat Catalog Index
- `.rmf`  - Acrobat Rights Management Document
- `.sequ` - Acrobat Action File
- `.xdp`  - Acrobat XML Data Package
- `.xfdf` - Acrobat Forms Document
- `acrobat:` URL protocol

Opening any registered type from Explorer or via Open With must launch Jovrel (reusing the existing single-instance window) and route the path through the existing open-file path. A type Jovrel can render opens; a type it cannot must produce a clear, non-crashing IN-APP message naming the type - never a silent failure and never a crash. Offline only; no network call.
