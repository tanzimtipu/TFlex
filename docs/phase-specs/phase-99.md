## Phase 99 - App home Open control: the fixed tile must not animate in edit mode, rename it to "Open Files", and verify every supported format opens (operator report TFL-380, commissioned as TFL-530, 2026-10-04)

**Operator request (product terms, TFL-380 / phase issue TFL-530).** On the app home page the open box must behave as a fixed, static control: (1) clicking the edit (pen) icon must NOT animate that box - the edit-mode animation belongs only to the editable tiles; (2) its label must read "Open Files", not "Open PDF"; (3) it must let the user open every file format TFlex can actually open, not only `.pdf`. Offline only; no network call.
