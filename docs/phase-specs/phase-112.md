## Phase 112 - Panels overhaul: Context Pair panels and shared panel primitives (phase issue TFL-854; operator driver TFL-810, 2026-10-05)

**Operator request (product terms, TFL-810 / phase issue TFL-854).** Redesign the workspace panels
using the committed Visual overhaul Panels package (`Visual overhaul/Panels/`) as the recommended
**Context Pair**: left = document navigation and workflow, right = current-selection properties or
export configuration, applied app-wide to Home's Recent and Sample document areas and to the left
navigator and right inspector across Pages, Edit, Review and Deliver. One consistent, ultra-modern,
simple and elegant system on the shared graphite/violet theme, complementary to the Quiet Precision
icon system and the Focus Dock. Precedence: consistency corrections > panel design spec > visual
references. Operator charge: "no conflict or overlapping contents." Out of scope: network features
(offline-first).

**CTO rulings:**

1. **Scope.** Renderer only: `src/renderer/components/**`, `src/renderer/state/**`, the panel sections
   of `src/renderer/styles.css`, and renderer unit tests. One small backend contract chunk adds the
   panel persistence fields to `src/shared/types.ts`, `src/main/services/settings.ts` and
   `test/unit/main/settings.test.ts`. qa owns `e2e/**`, `screenshots/**`, `test-fixtures/**`.
2. **Shared primitives, not per-workspace implementations.** One panel-shell, scoped-header, section,
   property-row, action-list and empty-state primitive; consume `panels.tokens.json` (16 px padding,
   20 px section gap, 52 px header, 9 px input radius, 14 px/500 section headings, 12 px secondary
   labels, 1 px boundary, 140 ms motion) through a scoped `.tf-panel` mapping - do NOT replace the app
   theme or restyle the dock, top bar/tabs, siderail, canvas, dialogs or button primitive.
3. **One list per object type + one synchronized selection model.** Selecting on the canvas or in the
   left navigator updates the same selection the right inspector reads. The right header always names
   the scope (Page 1 / N pages selected / Text object / Image / Field / Annotation / Export document).
   Without a selection, hide irrelevant editing controls and offer one concise next action; never
   duplicate an annotation list or empty state on both sides.
4. **State honesty.** For every new or reworked visible item record owning scope, authoritative model
   source, loading/unknown/empty/unsupported/error state, command ID, capability predicate and refresh
   dependencies; guard async results by document version and selection identity; lazily render
   thumbnails/analyses and virtualize long lists without losing scroll/selection; never claim Blank /
   Scanned / Editable / Signed / Ready without real supporting data; never copy the preview's
   illustrative records, guessed backend capabilities or simplified validation.
5. **Geometry.** Persist panel widths (left 240, 220-320; right 280, 260-380) and collapse state;
   layout changes update the document viewport used by Focus Dock centering and preserve zoom and
   selection; narrow windows may use a compact drawer, but the optional Single Inspector must share
   the same data and commands, not duplicate them.
6. **Motion + accessibility.** Reuse the shared motion tokens (140 ms), reduced-motion and
   high-contrast support, labelled inputs, focus separate from selection, keyboard-accessible
   resizing, 44 px coarse targets and text scaling. No extra approval step for a visual redesign;
   preserve existing command confirmation/overwrite/undo behaviour.
7. **No overlap.** Consume the shared Quiet Precision icon registry; do not fork a second icon or
   visual language. The CTO sequences panels so it does not overlap an uncommitted sibling overhaul
   and git-agent commits stay role-clean.
8. **Flow + evidence.** frontend-dev runs `npm run verify` plus the named targeted specs and returns a
   CONTROL-INDEX; qa runs focused verification, the CONTROL-INDEX sweep and before/after screenshots
   for Home and all four workspaces (empty/selected/loading/error, both themes, 100/125/150/200% DPI,
   resized/collapsed/narrow) and times the budget; the adversary runs diff-passes on layout
   persistence, delete/merge and export config; then phase-close QA and ONE local commit via
   git-agent. No push, tag, release or version bump without explicit operator approval.
