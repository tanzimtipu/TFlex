## Phase 121 - Home page vertical spacing: the enforced minimum-stack-gap rule (phase issue TFL-1396; CEO commission from TFL-1394, 2026-10-09)

**Operator request (product terms, TFL-1396).** On the Home page the intake drop zone ("Drop files to add them to the queue") sits flush against the editable tool row directly above it: the two regions abut with no vertical breathing room. Give that region clear vertical separation so the two never touch or overlap, and establish ONE durable, shared minimum vertical spacing rule (a named token on the design foundation) so this class of crowding cannot recur elsewhere in the UI. The gap must be maintained by construction - by consuming the shared rule - not by an ad hoc per-component margin. Applies at the default window size and at the minimum supported window size. Offline UI only; no network features.

The rationale is recorded in `docs/DESIGN-SYSTEM.md`.
5. **No unrelated change.** Do not restructure the hero, the tool row, the recent / sample sections, any other surface, or any theme. The token is additive; only `.welcome-intake` gains the margin.
