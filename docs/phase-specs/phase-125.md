## Phase 125 - Overall text legibility: raise contrast and crispness across the UI (phase issue TFL-1419; CEO commission from TFL-1418, 2026-10-09)

**Operator request (product terms, TFL-1419 from TFL-1418).** The overall app text reads faded / washed-out and is hard to read. Deliver a whole-app text-legibility pass so on-screen text is crisp and comfortably readable on every surface (Home, document workspace chrome, panels / inspector, tabs, dialogs, settings) and in every theme, without changing layout or the product's visual identity. Offline renderer UI only; no network features.

**CTO rulings:**

1. **Two measured root causes, both renderer-only.** (a) CRISPNESS: `src/renderer/styles.css:1597-1606` sets `body { -webkit-font-smoothing: antialiased; }`, which forces grayscale anti-aliasing on Windows and thins every glyph - the "washed-out" look; the platform default (ClearType / subpixel) must be restored. (b) CONTRAST: two visible-text ink tiers fall below WCAG 2.1 AA. Measured this phase (WCAG 2.1 ratio, light / dark / frosted): `--fg-faint` light `#94a3b8` = 2.10-2.56 on every chrome surface, dark `#5b626b` = 2.56-3.23 (frosted `--fg-faint` = `var(--tf-text-disabled)` clears at ~11.0); `--tf-text-supporting` `#667085` = 4.07 on light `--bg-sunken`, 4.19 on light `--bg-rail` / `--panel-bg`, 4.39 on light `--bg-secondary`, 4.16 on frosted `--bg-sunken` (dark `#929BAC` clears at 5.65-7.12).
2. **The ink tokens are the only lever; the ladder is retuned in place.** Raise `--tf-text-supporting` (`styles.css:46`) from `#667085` to `#5b6577` (verified >= 4.81 on light `--bg-sunken`, >= 4.95 on `--bg-rail`, >= 5.88 on `--bg-base`; >= 4.92 on frosted `--bg-sunken`), and keep `--tf-nav-helper-ink` (`styles.css:171` light, `:861` dark, `:1185` frosted) EQUAL to it in every theme (light `#5b6577`, dark `#929BAC`, frosted `#5b6577`). Dark `--tf-text-supporting #929BAC` is unchanged. `--fg-faint` is re-scoped as the DISABLED / decorative tier and is no longer used for visible text: every VISIBLE text rule that reads `var(--fg-faint)` is repointed to `var(--tf-text-supporting)`. Enumerated visible-text consumers to repoint: `.outline-empty` (`styles.css:5900`), `.thumb-empty` (`:7571`), `.ann-panel-row-page` (`:9283`), `.ann-panel-text-readonly` (`:9364`), `.tools-palette-entry-shortcut` (`:11173`), `.color-palette-count` (`:12177`), `.optimize-fft-value` (`:12515`), `.audit-bar-hint` (`:12629`), `.create-image-index` (`:12734`), `.ocr-suspects-pages` (`:14340`), `.ocr-suspects-page-count` (`:14386`), `.ocr-suspects-count-value` (`:14566`), `.command-palette-input::placeholder` (`:20050`), `.doc-info-section-empty` (`:22173`), `.intake-index` (`:24598`). Decorative / disabled exemptions KEEP `--fg-faint`: `.empty-state-mark` (`:4367`), `.thread-stream-row-meta [data-ann-icon]` (`:9429`), `.multi-pane-empty-icon` (`:17295`), `.command-palette-row-disabled .command-palette-row-desc` (`:20132`), `.accounts-divider` (`:20978`).
3. **No layout, no identity, no PDF pixels.** Only ink lightness / values and the one font-smoothing declaration change. No font-size, font-weight, spacing, geometry, hue, radius or motion change; no font is shrunk or emboldened; the accent violet and the semantic role hues are untouched; `--fg-on-page` (page-content ink) and every PDF pixel stay as they are; a document is never mutated. Muted / secondary text stays visibly lighter than primary so hierarchy survives (`--tf-text-supporting` remains lighter than `--fg-muted` in light; the dark ordering is preserved).
4. **Renderer only, minimal, no contract change.** Touch `src/renderer/styles.css` and the new / updated renderer unit specs only. No `src/shared/` contract change, no IPC, no new `AppSettings` field, no main-process work, no new dependency, no backend chunk, no network.
