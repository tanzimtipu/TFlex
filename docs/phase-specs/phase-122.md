## Phase 122 - Retire the canvas "Drop files to add them to the queue" hint (phase issue TFL-1399; CEO commission from TFL-1395, 2026-10-09)

**Operator request (product terms, TFL-1399).** In the document canvas a floating popup reads "Drop files to add them to the queue" (with the sub-line "PDFs open as tabs; images become one PDF."). Fully retire it: the popup must never appear on any canvas surface in any state (empty, loading, error, populated) or at any supported window size, and the string "Drop files to add them to the queue" must not appear on the canvas surface in the UI. Remove or permanently suppress the mechanism that produced it so a later state change cannot bring it back. If dropping files onto the canvas is a real, working feature it must keep working - only the popup goes. If the popup is a purely decorative / empty-state hint with no functional drop action behind it, remove the popup together with the code, state and tests that existed only to render it (no dead code, no orphaned CSS, no leftover string). Canvas surface only - the home-page drop zone and its spacing are out of scope (TFL-1396). Offline UI only; no network features.

**CTO rulings:**
